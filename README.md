# Brawl Click — Трофейный рывок

Отдельный фан-прототип для браузера. Локальный предпросмотр: http://127.0.0.1:5180/ . В Яндекс Играх этот проект пока не опубликован.

## Запуск и проверка

```powershell
npm install
npm run dev
npm test
npm run test:browser
npm run release
```

ZIP для загрузки: `artifacts/brawl-click-yandex.zip`. В архиве только production index.html и локальные игровые ресурсы; исходники, исследования и тесты не включаются. `npm run preview` — production-проверка на порту 4180. Пути относительные, игра запускается из вложенного пути.

## Игра

- 25-секундные рейды: роботы, гемы, монеты ×3, кубы +3 силы, соперники с двумя HP и бомбы. Цели двигаются до попадания или конца раунда. Пять режимов сменяются по завершённым раундам.
- 30 бойцов, команда из трёх, уровни 1–11, бонусы ролей, дубликаты, боксы, задания, трофейная дорога и престиж.
- У каждого бойца есть именованная активная способность. Шесть семейств: залп, помощник, лечение, щит, заморозка и ускорение. Перезарядка 12 секунд активного игрового времени; эффект и таймер сохраняются.
- Арена: 12 последовательных боссов с полноразмерной графикой. Броня, регенерация или сокращённый таймер. Босс атакует команду; замах предупреждает об ударе, кнопка уклонения защищает на 1,1 секунды и восстанавливается 2,5 секунды.
- Победа продвигает очередь, поражение оставляет того же босса. После 12 побед следующая глава сложнее. Финал даёт +1 постоянную звезду (+5% к добыче и базовому урону), 10+2×номер главы гемов и ещё 30 силы. Награды фиксируются вместе с исходом боя и не повторяются после перезагрузки.
- RU/EN, звук, локальное сохранение и SDK-облако, пауза при сворачивании, рекламе и модальных окнах.

## Реклама

Ежедневный дроп и колесо — только за подтверждённое видео. Четыре монетных бокса также открываются за видео с отдельными интервалами 3/5/10/20 минут. Есть отдельный бокс за гемы и рекламный звёздный дроп. Дополнительно: монеты, сила, гемы, ×2 добыча на две минуты, ×2 монеты результата/задания/офлайн-дохода и одно продолжение проигранного боя.

Периодическая полноэкранная реклама запрашивается после 3 минут сессии и 3 минут от любой рекламы, на переходе или продолжении результата. Короткий рейд/бой и открытие бокса не прерываются. Частоту и наличие объявления определяет SDK. В локальном режиме рекламные кнопки отключены, просмотр и награда не имитируются. Баннеры настраиваются в консоли платформы. У новой игры они пока не настроены: проект ещё не загружен в кабинет.

Сохранение `brawl-click.save.v1`, облако `brawlClickV1` отделены от первого кейс-симулятора. Не очищайте localStorage для обычного обновления игры.

## Версия 0.1.1

В магазине шесть боксов: 500 / 12500 / 60000 / 240000 монет, бокс бойца за 60 гемов и звёздный дроп только за видео. Мега требует 75 трофеев, эпик — 150. Монеты в обычных боксах составляют менее 20% цены. Особый бокс дня доступен только в Бонусах: раз в 24 часа за видео, вместе с прежними монетами и тремя гемами. В магазине его нет.

Три нажатия заряжают бокс, затем по очереди раскрываются монеты, сила, гемы и боец. Можно пропустить анимацию. Содержимое начисляется один раз до анимации; этап раскрытия сохраняется. Нажатия не меняют шансы. Бомба исчезает через 4 активные секунды без потери серии и без награды. Скилл и супер расположены рядом. Перед атакой босса большой отсчёт меняется на красное «ЖМИ УКЛОНЕНИЕ»; кнопка становится доступна на 1,1 секунды.

Телефон в одной сети с ПК: http://192.168.31.34:5181/ . Сервер запущен отдельным фоновым процессом и привязан к локальному адресу. Пока ПК выключен, адрес не работает. Прогресс локальных браузеров сохраняется отдельно, реклама локально отключена. Брандмауэр не изменялся.

## Версия 0.1.2

Свободный слот «+» открывает список полученных бойцов вне команды. Одно нажатие добавляет выбранного бойца, сохраняет состав и закрывает окно. Если доступных бойцов нет, окно объясняет, как открыть новых.

Музыка Brawl Stars меняется между меню, рейдом, ареной и результатом. Плавный переход 0,65 секунды. Музыка и эффекты имеют независимые выключатели и громкость в Настройках. Первый запуск звука — после нажатия. SDK-пауза и скрытие вкладки приостанавливают общий AudioContext; настройки сохраняются в прежнем слоте без сброса прогресса. Старое отключение звука при миграции отключает также музыку.

Карточка и архив новой игры: https://games.yandex.ru/console/application/637006#application-info-draft . Итоговый ZIP в artifacts, сведения о проверках — docs/QA-RU.md. Материалы карточки находятся в artifacts/yandex. На модерацию автоматически не отправлялась.
